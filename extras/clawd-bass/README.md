# Clawd on Bass

A pixel-art Clawd playing a two-bar funk bass groove, drawn frame by frame on a 56×40 canvas.
Open `index.html` in a browser. No build step, no images.

- The **打开声音** (sound on) button plays the groove through Web Audio (bass, kick, snare, hats).
- **速度** (tempo) slider: 72–140 BPM.
- Click or tap the stage for a slide solo.
